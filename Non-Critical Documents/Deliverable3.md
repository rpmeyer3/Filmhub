CSCI 4050/6050 – Software Engineering 
Term Project – Deliverable #3 (Sprint 1: Implementation) 
Cinema E-Booking System (CES) 
1. Objective 
This deliverable represents the first sprint implementation of the CES project. Teams must demonstrate 
a working version of the system that integrates the front-end, backend, and the database for the 
following features: 
• Home Page – movies pulled dynamically from DB. 
• Search – search movies by title. 
• Filter – filter movies by genre. 
• Trailers – embedded and playable trailers. 
• Movie Details Page – selecting a movie must display its details (title, rating, description, poster, trailer, 
showtimes). 
• Prototype Booking Navigation – selecting a showtime should open a Booking Page (UI only) with movie 
title and showtime displayed. Booking logic (seats, checkout, etc.) will be implemented in later sprints. 
2. Requirements 
1. Home Page 
• - Retrieve movies dynamically from the Movie database table (not hardcoded). - Display under Currently Running and Coming Soon. - Show hardcoded showtimes for each movie (e.g., 2:00 PM, 5:00 PM, 8:00 PM). 
2. Movie Details 
• - When a user selects a movie, a Movie Detail Page must appear. - Display poster, title, rating, description, available showtimes, and trailer. 
3. Search 
• - Search by title and display matching movies. 
4. Filter 
• - Filter by genre and update displayed results accordingly. 
5. Trailers 
• - Embed and play trailers on either the Home Page or the Movie Detail Page. 
6. Prototype Booking Page (UI only) 
• - When a showtime is selected, the system must display a Booking Page. - This page should show the selected movie and showtime, and all other values that the user needs 
to enter. - Do not implement seat selection, pricing, or checkout yet.
