# Cinema E-Booking System - Sprint 1 Frontend

## 🎬 Deliverable Requirements Met ✅

### 1. Home Page (40 pts) ✅
- Movies pulled dynamically from database
- Display "Currently Running" and "Coming Soon" sections  
- Hardcoded showtimes (2:00 PM, 5:00 PM, 8:00 PM)

### 2. Movie Details Page (20 pts) ✅
- Movie selection displays detailed information
- Shows poster, title, rating, description, showtimes
- Embedded trailer functionality

### 3. Search Functionality (20 pts) ✅
- Search movies by title
- Real-time search integration with backend

### 4. Filter Functionality (20 pts) ✅
- Filter movies by genre
- Dynamic results update

### 5. Trailer Implementation (20 pts) ✅
- Embedded YouTube trailer on movie details page
- Playable trailer interface

### 6. Booking Page Navigation (10 pts) ✅
- Showtime selection opens Booking Page
- Displays selected movie and showtime
- UI-only implementation

This is a [Next.js](https://nextjs.org) project integrated with Django backend.
