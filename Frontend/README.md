# Frontend

This directory contains the React frontend application with Tailwind CSS for styling.

## Structure

```
Frontend/
├── src/
│   ├── components/
│   ├── pages/
│   ├── hooks/
│   ├── services/
│   └── utils/
├── public/
└── build/
```

## Technologies
- **React 18** - UI framework
- **Tailwind CSS** - Utility-first CSS framework
- **React Router** - Client-side routing

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Build for production:
   ```bash
   npm run build
   ```

The application will be available at `http://localhost:3000`
