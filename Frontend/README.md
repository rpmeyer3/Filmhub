# Frontend

This directory contains the React frontend application with Tailwind CSS for styling.

## Structure

```
Frontend/
├── src/
│   ├── components/
│   ├── pages/
│   ├── hooks/
│   ├── services/
│   └── utils/
├── public/
└── build/
```

## Technologies
- React 18 - UI framework
- Tailwind CSS - Utility-first CSS framework
- React Router - Client-side routing

## Prerequisites

- Node.js 16+ and npm - Download from [nodejs.org](https://nodejs.org/)
  - This is required to run the React frontend
  - npm comes bundled with Node.js

## Getting Started

1. First, install Node.js if you haven't already:
   - Go to https://nodejs.org/
   - Download the LTS version for Windows
   - Run the installer and follow the setup wizard
   - Restart your command prompt after installation

2. Verify installation:
   ```cmd
   node --version
   npm --version
   ```

3. Navigate to Frontend directory:
   ```cmd
   cd Frontend
   ```

4. Install dependencies:
   ```cmd
   npm install
   ```

5. Start the development server:
   ```cmd
   npm start
   ```

6. Build for production:
   ```cmd
   npm run build
   ```

The application will be available at `http://localhost:3000`
